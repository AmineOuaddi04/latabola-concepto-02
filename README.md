# La Tabola — concepto 02

Segunda dirección web para La Tabola Gastrobar (Logroño), construida como una experiencia de bar contemporáneo con tipografía rotunda, fotografía ambiental y carta interactiva. HTML, CSS y JavaScript sin compilación.

## Investigación

- [La Tabola oficial](https://latabola.es/) y su [carta digital](https://latabolasierra.revosolo.works/an-store/digital-menu): dirección, contacto, trayectoria, categorías y productos.
- [Bar Raval](https://www.thisisbarraval.com/): portada inmersiva, atmósfera de bar y navegación mínima.
- [Legado](https://www.legadorestaurants.com/): escala del nombre y fotografía ambiental oscura.
- [Pez Tortilla](https://peztortilla.com/): personalidad verbal directa y tortilla como elemento reconocible.
- [Jaleo](https://www.jaleo.com/): energía cromática y carácter contemporáneo de la cocina española compartida.

La composición y el sistema visual son originales para esta propuesta. Las dos fotografías son imágenes editoriales generadas; no representan el interior real ni platos fotografiados en La Tabola. La carta interactiva muestra una selección de productos verificados en la carta oficial sin replicar precios que puedan cambiar. El enlace a la carta oficial permite consultar la versión vigente.

## Recursos generados

- `assets/mesa-viva.webp`: escena editorial de personas compartiendo tapas y vino, con zona oscura para el gran titular.
- `assets/tortilla-roja.webp`: composición cenital gráfica de tortilla y croquetas sobre una mesa roja.

Antes de adoptar esta propuesta como web oficial conviene sustituir esas imágenes por fotografías propias del negocio.
